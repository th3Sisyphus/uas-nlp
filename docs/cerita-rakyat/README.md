## Cara Memakai

1. Salin berkas yang disetujui ke `korpus/cerita/`.
2. Jalankan `python pengujian/uji_sistem.py`.
3. Perbarui jumlah cerita dan adegan di `Readme.md` dan `ReadMe.txt`.
